# Getting help

| You want to... | Go to |
|---|---|
| Learn how to do something | The [wiki](https://github.com/A21-devs/Virtual-Machine-Manager/wiki): installing, your first VM, hardware settings, profiles, troubleshooting |
| Ask a question or share an idea | [Discussions](https://github.com/A21-devs/Virtual-Machine-Manager/discussions) |
| Report a bug | [New issue](https://github.com/A21-devs/Virtual-Machine-Manager/issues/new/choose) using the bug form. Paste the VM's Log tab, it usually has the answer |
| Report a security problem | Privately, see [SECURITY.md](SECURITY.md). Not in a public issue |
| See what's planned | The [roadmap](https://github.com/A21-devs/Virtual-Machine-Manager/wiki/Roadmap) |

## What to expect

This is maintained by one person in their spare time. I read every issue and discussion, usually within a few days. If I need more detail I'll ask in the thread. When something is fixed, the issue gets closed with the PR that fixed it and the release it ships in. If a request doesn't fit the project I'll say why instead of leaving it open.

Answers that will help other people end up in the wiki or the FAQ, so they don't get lost in a thread.
